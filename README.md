Kya Banau? – AI-Powered Weekly Meal Planner
“Kya Banau?” is an intelligent food recommendation web application that generates a personalized weekly meal plan based on user inputs such as age, weight, height, dietary preferences, health conditions, and regional cuisine.

The app uses AI to suggest simple, home-cooked Indian meals tailored to individual needs. It focuses on practical, easy-to-make recipes and supports multiple health conditions.

Features:
AI-generated weekly meal plans (Mon–Sun)
🇮🇳 Region-based Indian cuisine (North, South, etc.)
Health-aware recommendations (Diabetes, BP, etc.)
Veg / Non-veg options
Downloadable meal plan (PDF)
Clean, modern UI with animations
Deployable web app

Tech Stack:
Next.js (Frontend + Backend)
Tailwind CSS (UI)
Groq API (AI)
jsPDF (PDF generation)
